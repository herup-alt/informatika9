Bab 1 • Moda Belajar Lanjutan

Analisis Data & Algoritma Lanjutan

Mengolah data nyata menjadi informasi bermakna dan menyusun logika pemrograman menggunakan percabangan serta perulangan.

T1

Topik 1: Pengolahan & Interpretasi Data

Data vs Informasi: Data adalah fakta mentah (angka, teks, gambar) yang belum diolah. Informasi adalah data yang telah diproses, diorganisasi, dan diberi konteks sehingga memiliki makna bagi pengambilan keputusan.

1. Pengumpulan

Survei, observasi, wawancara, atau wawancara digital.

2. Pembersihan

Menghapus data ganda, kosong, atau tidak valid.

3. Pengolahan

Penerapan rumus & agregasi tabel (Excel/Sheets).

4. Visualisasi

Menampilkan diagram batang, garis, atau lingkaran.

Rumus Dasar Spreadsheet (MS Excel / Google Sheets)

Fungsi Kegunaan Sintaks / Contoh
SUM Menghitung total penjumlahan angka dalam rentang sel. =SUM(C2:C10)
AVERAGE Menghitung nilai rata-rata dari rentang sel. =AVERAGE(C2:C10)
MAX Mencari nilai tertinggi / terbesar. =MAX(C2:C10)
MIN Mencari nilai terendah / terkecil. =MIN(C2:C10)
COUNT Menhitung jumlah sel yang berisi nilai angka. =COUNT(C2:C10)

Studi Kasus: Data Survei Kebiasaan Belajar Mandiri (Jam/Minggu)

T2

Topik 2: Logika & Pemrograman Python

Berpikir Komputasional (Computational Thinking): Metode pemecahan masalah dengan mendekomposisi masalah, mengenali pola, melakukan abstraksi, dan merancang langkah-langkah sistematis (algoritma).

Percabangan (Decision IF / IF-ELSE)

Pengecekan kondisi bernilai True atau False untuk menentukan alur eksekusi program.

if nilai >= 75:
    print("Lulus")
else:
    print("Remedial")

Perulangan (Loops FOR / WHILE)

Eksekusi serangkaian instruksi secara berulang selama kondisi terpenuhi.

for i in range(1, 6):
    print("Angka ke-", i)

5 Contoh Program Python Utama (Lengkap Penjelasan):

1. Program Menentukan Bilangan Genap / Ganjil
Operator Modulo (%) 
# Input angka dari pengguna
angka = int(input("Masukkan sebuah angka: "))

if angka % 2 == 0:
    print(f"{angka} adalah bilangan GENAP")
else:
    print(f"{angka} adalah bilangan GANJIL")

Penjelasan: Operator % (sisa bagi) mengecek apakah sisa pembagian dengan 2 adalah 0. Jika ya, angka bernilai GENAP.

2. Program Kelulusan Berdasarkan Nilai KKM (75)
Percabangan Bertingkat 
nilai = float(input("Masukkan nilai akhir siswa: "))

if nilai >= 90:
    predikat = "A (Sangat Baik)"
elif nilai >= 75:
    predikat = "B (Baik - Lulus KKM)"
else:
    predikat = "C (Perlu Bimbingan Remedial)"

print("Predikat Kelulusan:", predikat)
3. Program Menhitung Jumlah Total Nilai
Akumulator Data 
data_nilai = [80, 75, 90, 85, 95]
total_nilai = 0

for n in data_nilai:
    total_nilai += n

print("Daftar Nilai:", data_nilai)
print("Total Penjumlahan Nilai:", total_nilai)
4. Program Perulangan Mencetak Angka Genap 2-10
FOR Loop Range 
print("Mencetak Angka Genap:")
for i in range(2, 11, 2):
    print("Angka:", i)
5. Program Menghitung Rata-Rata Nilai
Fungsi len() & sum() 
nilai_siswa = [88, 72, 95, 78, 85]
banyak_data = len(nilai_siswa)
jumlah = sum(nilai_siswa)
rata_rata = jumlah / banyak_data

print("Banyak Siswa:", banyak_data)
print("Rata-rata Nilai:", rata_rata)
Bab 2 • Kewargaan & Keamanan

Dampak Sosial Informatika (DSI)

Menjadi warga digital yang cerdas, beretika, aman dari ancaman siber, dan bijak dalam bermedia sosial.

T1

Topik 1: Etika Digital & Keamanan Informasi

Kewargaan Digital & Etika

Kemampuan menggunakan teknologi informasi secara bijak, bertanggung jawab, menghormati hak cipta (HAKI), tidak melakukan plagiarisme, dan menjaga kerahasiaan data pribadi.

Cybercrime & Threat Types

Kejahatan siber meliputi Phishing (penipuan tautan palsu pencuri akun), Malware (virus perusak sistem), dan pencurian data pribadi (Identity Theft).

Prinsip Utama Keamanan Digital Siswa:

Kata Sandi Kuat Minimal 12 karakter kombinasi huruf besar, kecil, angka, dan simbol (contoh: SmPBina#2026!).
Autentikasi Dua Faktor (2FA) Menggunakan verifikasi tambahan lewat kode OTP / aplikasi authenticator.
Jejak Digital (Digital Footprint) Segala unggahan dan komentar di internet bersifat permanen dan sulit dihapus sepenuhnya.
Sikap Menghadapi Pesan Mencurigakan Jangan klik link asing, abaikan iming-iming hadiah tak jelas, dan laporkan.
T2

Topik 2: Penggunaan Media Sosial Beretika

Media sosial memiliki dampak ganda. Dampak positifnya meliputi kemudahan kolaborasi, pembelajaran daring, dan pengembangan ide kreatif. Namun, penggunaan tanpa etika menimbulkan dampak negatif berupa perundungan siber (*cyberbullying*), penyebaran berita bohong (*hoaks*), dan kecanduan digital.

Panduan Cek Fakta Kebenaran Berita (Saring Sebelum Sharing)

  1. Cek Sumber Berita: Pastikan dipublikasikan oleh media resmi terverifikasi.
  2. Periksa Judul Provokatif: Berita hoaks sering menggunakan judul bertulisan KAPITAL yang menggebu-gebu.
  3. Verifikasi Foto / Gambar: Gunakan Reverse Image Search di Google untuk mengecek keaslian foto.
  4. Bandingkan Referensi: Cari berita topik senada di minimal 2 portal berita tepercaya.

Topik 2: Internet of Things (IoT)

Internet of Things (IoT) adalah jaringan perangkat fisik (benda) yang dilengkapi sensor, perangkat lunak, dan konektivitas internet sehingga mampu mengumpulkan dan mempertukarkan data secara otomatis tanpa campur tangan manusia.

3 Proyek Aplikasi IoT Sekolah & Rumah Tangga:

1. Lampu Otomatis (LDR)

Lampu taman sekolah menyala otomatis saat sensor LDR mendeteksi kondisi malam hari (kegelapan).

2. Monitoring Suhu Ruangan

Sensor DHT11 mengukur suhu lab komputer dan menyalakan kipas/AC jika suhu melebihi 28°C.

3. Penyiraman Tanaman

Sensor kelembapan tanah menyalakan pompa air ketika tanah kebun sekolah dalam kondisi kering.
